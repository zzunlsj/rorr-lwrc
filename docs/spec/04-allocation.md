# 04. 선수별 배분 — 관여 회귀 (+ 시야 · CC · 보호)

교전 파이를 선수에게 나누는 지분 `w_i`. **정본은 관여 회귀**이고, 고정 가중은 **기준선(prior)**으로 함께 산출해 비교한다.

## 4.1 관여 피처 8종

각 피처는 클러스터 안에서 선수별 값 `x_ik`로 측정한다.

| k | 피처 | 측정 | 비고 |
|---|---|---|---|
| dmg | 딜 | **프레임 누적 챔피언 대상 피해의 구간 [s, e] 증가분** | 킬 피해 분해(죽은 대상에게 넣은 딜만)는 결과에 묶여 있어 쓰지 않는다 |
| assist | 어시스트 | 클러스터 내 챔피언 킬의 assistants 등장 횟수 | 게임이 CC·실드·힐 제공을 인정한 값. 킬이 나야만 존재해 계수 과대 가능 |
| absorb | 흡수 | 구간 내 `Σ max(0, health[t] − health[t+1])` | 레벨업으로 최대 체력이 바뀐 프레임·부활 프레임 제외 |
| presence | 존재 | 씨앗별 반경 **2,300** 안에 **생존 상태로** 있던 프레임 비율 | 씨앗 중 하나라도 반경 안이면 참여(OR 판정) |
| vision_provided | 시야 제공 | 시야창 동안 시야 구역 안에서 살아있던 **본인 설치 와드의 생존 초 합** | §4.3 |
| vision_denied | 시야 제거 | 시야창 동안 시야 구역 안에서 **본인이 제거한 상대 와드 수** | §4.3 |
| cc | CC | 프레임 누적 `TOTAL_TIME_CROWD_CONTROL_DEALT_TO_CHAMPIONS`의 구간 [s, e] 증가분 | §4.3b. 결정 19 |
| protect | 보호 | 프레임 누적 `TOTAL_DAMAGE_SHIELDED_ON_TEAMMATES + TOTAL_HEAL_ON_TEAMMATES`의 구간 [s, e] 증가분 | §4.3b. 결정 19 |

반경 근거: 자체 쟁탈전 와드 분포에서 도출한 동심원 모델 — pit 650 / control 2,300 / vision 3,300.
존재는 "교전에 영향을 줄 수 있는 거리"(control), 시야는 "교전을 위해 미리 깔아두는 거리"(vision).

## 4.2 관여 회귀 (정본)

개인별 결과값이 없으므로 **클러스터(팀) 단위로 학습하고 개인 단위로 평가**한다.

```
Swing_c = Σ_k β_k · (우리팀 Σ_i x_ik − 상대팀 Σ_j x_jk)_c  +  γ · 통제항_c  +  ε

  Swing  = (ΔG_us − ΣRisk_us − 시간항) − (ΔG_opp − ΣRisk_opp − 시간항)   ← 데스 비용·시간 경과 제외한 순 교전 스윙
  통제항 = 교전 직전 G 차이 · 게임 시각 · 클러스터 길이 · 참가 인원

개인 지분:  w_i = Σ_k β_k · x_ik
```

- 지분은 클러스터 안에서 정규화되므로 **β의 절대 크기는 무관하고 비율만 의미**가 있다.
- C와 D를 따로 회귀하지 않는다 — 두 채널이 같은 지분을 쓰기 때문.

| 항목 | 설정 |
|---|---|
| 추정 | **비음수 제약(NNLS) + 리지** — 음수 β는 "관여했는데 지분이 깎이는" 결과를 만든다 |
| 분할 | 경기 단위 크로스피팅 (G와 동일 fold) |
| 포지션별 계수 | **하지 않음** — 포지션 분모로 이미 정규화하므로 순환·과적합 위험 |
| prior 수축 | `w = (n·β_회귀 + k·β_초기) / (n + k)` — 시야 2종·cc·protect의 초기값은 0 |
| 리포트 | fold별 β, 부트스트랩 신뢰구간 |

## 4.3 시야 피처 정의

```
시야창    = [s − 30초, e]                         (config: allocation.vision_pre_window_sec)
시야 구역 = 클러스터 씨앗들의 반경 3,300 합집합    (config: allocation.vision_radius)

시야제공_i = Σ_(i가 설치한 와드, 위치가 시야 구역 안) | 와드 생존 구간 ∩ 시야창 | (초)
시야제거_i = 시야창 동안 시야 구역 안에서 i가 제거한 상대 와드 수
```

- **와드로 인정하는 종류**: `config: allocation.vision_ward_types`. `wardType = unknown`(요릭·쉔·진·바드 등 챔피언 고유 설치물)은 **시야 피처에서 제외**한다 — L1에는 원본대로 남기고 제외 건수를 리포트 (결정 16).
- 와드 생존 구간 = 설치 ~ 제거. 제거 이벤트가 없으면 종류별 지속시간 규칙으로 만료 추정(제어 와드는 제거될 때까지). 지속시간·설치 한도는 `config: allocation.ward_rules`에 **공식 패치값 표**로 두고, 실측 설치→제거 분포와 대조해 검증한다 (결정 17).
  - 만료: 지속시간이 있는 종류는 설치 + 지속시간에 끝난다 (`removal_kind = expired`).
  - 교체: 설치 한도를 넘으면 같은 그룹의 가장 오래된 와드가 사라진다. raw에 이벤트가 없으므로 선수별로 재현한다 (`removal_kind = replaced`).
  - 셋 중 가장 이른 시각(제거·만료·교체)이 생존 구간의 끝이다.
- **생존 초로 재는 이유**: 설치 직후 제거된 와드는 거의 기여하지 못했고, 오래 살아남은 와드는 크게 기여했다.
- **부수 효과**: 시야·존재 덕분에 킬 없는 오브젝트 클러스터에서도 Σw > 0이 되어, 무혈 오브젝트 교전의 개인 귀속이 일부 가능해진다.
- 와드 이벤트가 없는 게임: 시야 피처를 **0으로 채우지 않는다**. 회귀 학습에서 제외하고, 산출은 나머지 피처만으로 (`spec/06` §2).

## 4.3b CC · 보호 피처 정의

- dmg와 같은 방식: `stats[]` 누적값의 구간 [s, e] 증가분. 결과(킬 여부)와 무관하게 측정된다.
- 누적값이 감소하거나 결측인 프레임은 **0으로 채우지 않는다** — 탐지·플래그하고 해당 게임은 이 피처 없이 회귀 학습에서 제외 (`spec/06` §2와 같은 원칙).
- prior(§4.4) 가중은 0 — 기준선은 기존 고정 가중 그대로 두고, 회귀에서만 계수를 받는다.
- assist와 공선성이 있을 수 있다(assist가 CC·실드·힐 제공을 일부 반영). β·부트스트랩 신뢰구간으로 보고한다.

## 4.4 기준선 — 고정 가중 (prior)

```
w_i = 1.0·share_dmg + 0.5·share_assist + 0.3·share_absorb + 0.2·share_presence
share_k[i] = x_ik / Σ_(같은 팀) x_k        # 각 성분을 클러스터 내 팀 점유율(0~1)로 먼저 정규화
결측 폴백(딜 명세 없는 킬): killer 1.0 / assist 0.5
```

## 4.5 정본 채택 기준 — 신뢰도

"서포터가 올라갔다"는 기대한 결과의 확인일 뿐이라 순환적이다. 객관 기준:

> **같은 선수의 시즌 전반 vs 후반 LwRC+ 상관(split-half)이 prior 가중보다 회귀 가중에서 높아지는가.**

보조: 클러스터 회귀 아웃오브샘플 R², 팀 LwRC 합의 다음 구간 승률 예측력, β 부호·안정성.
**β_시야·β_cc·β_protect가 유의하지 않으면 유의하지 않다고 보고**한다(삭제하거나 강제하지 않는다).

## 4.6 남는 한계

회귀가 주는 것은 "어떤 종류의 관여가 평균적으로 큰 스윙과 함께 나타나는가"이지 특정 교전의 인과가 아니다.
CC·보호 피처(§4.3b)는 양을 재지 결정성을 재지 않는다 — 결정적 CC 한 방을 넣고 딜이 적은 이니시에이터는 여전히 과소평가될 수 있다.
