# 05. 보존 항등식과 시즌 LwRC+

## 5.1 보존 항등식 (게임별 · 팀별)

```
Σ_i C_i + Σ_i Risk_i + 팀 계정 = G(END, us) − G(0, us)
```

- 텔레스코핑으로 항상 성립해야 하며 깨지면 귀속 누수. 잔차 < ε (`config: identity.epsilon`).
- **통과한 게임만 집계에 포함**, 미통과는 `excluded_games`에 사유와 함께.
- 우변은 "팀 실제 골드 변화"가 아니라 **기대 골드의 총 변화**(학습 G). G(0)은 누구에게도 귀속하지 않음.
- **D는 항등식에 들어가지 않는다** (상대 장부). 대신 상대 장부와 교차검증한다: 우리 D 파이 총량 = 상대 클러스터 잔여의 음수 부분 총량 (`spec/07` #6).
- C_i = 실현 골드(클러스터 + 드리프트) + 가속 C 파이 배분 (결정 27). 출력에는 두 하위 성분을 나눠 둔다.

## 5.2 게임별 LwRC

```
LwRC_i(game) = Σ C_i + Σ D_i + Σ Risk_i         (골드 단위)
```

## 5.3 scope별 집계 — 비율의 평균이 아니라 합의 비율

scope 목록과 포함 게임은 `contracts/output-web.md` §1.

```
rate_i(scope)     = Σ_(scope 내 게임) LwRC_i  /  Σ_(scope 내 게임) 플레이 분_i
denom(scope, pos) = Σ_(scope·포지션 pos 전원) LwRC  /  Σ_(scope·포지션 pos 전원) 플레이 분
LwRC+_i(scope)    = 100 × rate_i(scope) / denom(scope, pos_i)
```

- **scope마다 rate·분모를 따로 계산**한다. G와 배분 β는 2026 전체로 한 번 학습한 것을 공유.
- 게임별 LwRC+를 평균내지 않는다 — 짧은 게임의 극단값이 과대 반영되므로. **분자·분모 모두 플레이 분 가중.**
- 분모 모집단: 해당 scope의 모든 게임·모든 선수(리그 무관). LCK scope는 LCK 선수만.
- 표본 부족 구간: 분모는 prior 수축, 극단값은 ±3σ 윈저라이즈.
- 단위: 숫자만 (`126` = 평균 대비 +26%). **음수 허용**, 바닥 처리 없음.

## 5.4 Gold +/G

```
pg_i(scope) = (rate_i − denom(scope, pos_i)) × 플레이 분_i / 게임 수_i
```

포지션 평균 대비 게임당 초과 골드(절대량). 캐리가 크게 나오는 것이 정상. LwRC+(상대 지표)와 함께 표시한다.

## 5.5 게임 길이 공정성

1차 보정은 분당 환산. 산출 후 **게임 길이 vs 선수 게임별 rate 상관**을 확인하고,
|corr| > 0.2이면(`config: season.length_corr_threshold`) 분모를 `(포지션, 길이 버킷: ≤25 / 25~35 / 35+분)`으로 층화한다.
승리 가치로 가중하지 않는다(그건 WAR의 역할).
