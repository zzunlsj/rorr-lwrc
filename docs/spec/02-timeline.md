# 02. 타임라인 분할 — 클러스터와 드리프트

## 2.1 씨앗 이벤트

```
champion_kill
building_destroyed
epic_monster_kill  중 monster_type ∈ {dragon, baron, riftherald, horde, atakhan}   (config: cluster.seed_monsters)
```

**정글 캠프(raptor, gromp, krug, wolf, blueCamp, redCamp, scuttleCrab)는 씨앗이 아니다.**
포함하면 클러스터가 게임을 삼킨다 (실측: 클러스터 20개 → 8개, 최장 522초, 커버리지 88%).

`turret_plate_destroyed`도 씨앗이 아니다 — 글로벌 골드는 total_gold에 반영되어 드리프트 C로 자동 귀속된다.

## 2.2 클러스터

```
s = 첫 씨앗 − 10초                      (config: cluster.window_sec)
e = 마지막 씨앗 + 10초
씨앗 간격 ≤ 10초이면 같은 클러스터로 연쇄 병합   (config: cluster.merge_sec)
경계 절단: s < 0 → 0,  e > 게임 종료 → 종료 시각
ΔG는 s·e에 가장 가까운 프레임의 G로 계산
```

- **10초 근거**: LoL 멀티킬 판정(더블~쿼드라)과 동일 기준 — 라이엇 자신의 "연속된 한 교전" 정의.
- **−10초로 시작하는 이유**: 이벤트 타임스탬프는 결과가 확정된 순간이다. 그 시점을 기준으로 잡으면 교전 변화가 기준점에 이미 흡수된다.
- **+10초의 역할**: 여파(현상금 반영, 부활 타이머 세팅, 버프 점등, 추격킬) 수집.
- **길이** = `20초 + (마지막 씨앗 − 첫 씨앗)`. 단일 씨앗이면 최소 20초, 상한 없음(연쇄 교전은 하나로 보는 게 의도).
- **경고**: 클러스터 길이가 180초를 넘으면 로그 + 경고 (`config: cluster.warn_len_sec`) — 씨앗 필터 불량의 조기 감지.

## 2.3 기대치 (3게임 실측 기준)

| 길이대 | 비율 | 성격 |
|---|---|---|
| 20초 (단일 씨앗) | 약 45% | 무혈 오브젝트, 솔로킬 |
| 21~40초 | 약 20% | 소규모 교전 |
| 41~100초 | 약 30% | 한타 |
| 100초+ | 약 5% | 연쇄 난전 |

교전 커버리지 **약 40%**가 정상. 70% 초과 = 씨앗 과다, 20% 미만 = 누락. **길이로 ΔG를 정규화하지 않는다.**

## 2.4 드리프트

클러스터의 **보집합**. 인접 프레임 루프로 처리하지 말고 **명시적으로 계산**한다 — 경계에서 값이 새면 항등식이 깨진다.
클러스터와 드리프트는 빈틈·겹침 없이 게임 전체를 분할해야 한다.
