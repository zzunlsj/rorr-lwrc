# 01. G — 학습된 기대 골드

## 1.1 레이블 (확정)

```
y(t, side) = gold(side, t + H)                              , 게임이 t+H까지 이어질 때
           = gold(side, END) + rate(side) × (t + H − END)   , t+H가 종료 이후일 때

H          = 10분                                           (config: g.label_horizon_min)
rate(side) = 종료 직전 3분간 해당 팀의 분당 골드 수입        (config: g.censor_rate_window_min)
```

**고정 지평인 이유** — "최종 팀 골드"를 레이블로 쓰면 **크게 이기는 팀일수록 게임을 빨리 끝내 최종 골드가 적어지는** 교란이 생긴다.
그러면 바론을 먹고 끝내는 플레이가 음수 ΔG를 받는다. "앞으로 10분 동안의 기대 골드"는 퍼포먼스 질문에 정확히 맞고, 공개 블로그의 설명과도 일치한다.

**검열(censoring) 보정인 이유** — 게임 종료는 지평을 잘라내는 사건이다. 잘린 만큼을 **양 팀 모두 직전 수입 속도로 외삽**한다.
승리 보너스는 주지 않는다 — LwRC+는 승리가 아니라 퍼포먼스를 재므로, 종료는 "중립적 절단"이다. 게임을 빨리 끝내는 것이 손해도 이득도 되지 않는다.

## 1.3 학습 설계

| 항목 | 설정 |
|---|---|
| 모델 | 선형회귀 + 리지 (계수 = 단가표, 부호 검증 가능). 비선형은 선형이 검증 통과한 뒤 |
| 학습 샘플링 | 30초 간격 (1Hz 전체는 인접 중복이 커서 불필요). **산출은 1Hz 그대로** |
| 분할 | **경기(match) 단위** — 같은 시리즈의 게임이 train/test에 갈라지면 누수 |
| 검증 분할 | 시간 홀드아웃: 앞 75% 기간 학습 / 뒤 25% 검증 — 패치 변화에 대한 실전 성능 |
| 최종 산출 모델 | **경기 단위 K-fold 크로스피팅** (K=5): 각 게임은 자신의 경기를 제외하고 학습한 G로 산출 |
| 패치·대회 | 피처(더미)로 포함, 분리 학습하지 않음 |
| 리지 α | 경기 단위 내부 교차검증으로 선택 |

## 1.4 ΔG 산출

```
ΔG = G(t₂) − G(t₁)
선형일 때: ΔG = Σ βₖ · Δxₖ        ← 피처별 자동 분해, β = 단가표
```

- **시간 항**: 시간 피처(t, t²)의 기여 `β_t·Δt + β_t²·Δ(t²)` 는 교전 효과가 아니라 시간 경과 몫이다.
  클러스터 ΔG에서 이 몫을 빼서 **팀 계정**으로 보낸다 (`spec/03`).
- **종료 조건**: `G(END) := y(END)` — 종료 시점은 모델 예측이 아니라 관측(검열 보정) 값으로 고정. 마지막 ΔG에 모델 오차가 끼지 않게.
- G(0)은 플레이 이전의 기대치라 누구에게도 귀속하지 않는다.

## 1.5 비교 기준선 — prior G

같은 게임을 이전 근사식(prior G)으로도 산출해 비교한다. prior G는 주 엔진이 아니라 **기준선**이다.

```
G_prior(t, side) = gold[side, t] + R(t) × M(t, side)
  R(t) = r̄ × min(H, 남은 분)      r̄ = 팀 분당 평균 골드 (자체 데이터로 재산출)
  M    = 1 + 0.30·(생존차/5) + 0.05·드래곤 스택차 + 0.03·(상대 타워 손실 − 우리 타워 손실) + 0.10·바론(우리)
```

핵심 비교: **팀 계정 크기가 학습 G에서 줄어드는가** (학습 G가 게임을 더 잘 이해한다는 직접 증거).
