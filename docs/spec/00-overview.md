# 00. 지표 정의와 전체 흐름

## 정의

LwRC+는 **선수 퍼포먼스 지표**다. 골드는 "이 선수가 얼마나 잘하고 있는가"를 재는 단위이며, 승리로의 환산은 상위 지표(LoL WAR)의 몫이다.

```
LwRC+  ─ 선수 퍼포먼스 (골드 생산 C + 차단 D − 허용 Risk, 범위·포지션 보정)
  ↓  (별도 설계 — 이 저장소 범위 밖)
LoL WAR = (골드 퍼포먼스 + 시야·맵 + 비골드 교전 기여 + 포지션 보정 + 대체 수준) ÷ 승리당 골드
```

야구의 wRC+(타격 퍼포먼스) → WAR(승수) 구조와 동일. LwRC+에 승리를 설명하는 부담을 지우지 않는다 —
골드 열세 역전승 같은 게임은 지표의 결함이 아니라 범위 밖이다.

## 전체 흐름

```
게임 로그(1Hz 프레임 + 이벤트)
  ↓
상태 벡터 x(t, side)                         ← contracts/input.md §2
  ↓
학습 G:  G(t, side) = fθ(x)                  ← spec/01 (고정 지평 레이블)
  ↓
타임라인 분할: [교전 클러스터] ∪ [드리프트]    ← spec/02
  ↓
Risk(데스 단위) → C·D 파이 → 선수 배분 → 드리프트 귀속   ← spec/03, spec/04
  ↓
보존 항등식 검증 → 게임별 LwRC                ← spec/05
  ↓
scope별 집계 → 포지션 분모 → 선수별 LwRC+       ← spec/05, contracts/output-web.md
```

## 세 채널

| 채널 | 정의 | 자팀 항등식 |
|---|---|---|
| C (Creation) | 본인 실현 골드 + 교전에서 우리 팀 골드 **속도(V)를 올린** 몫 (가속) | 포함 |
| D (Denial) | 교전에서 상대 팀 골드 **속도를 내리게 한** 몫 (감속) | **제외** (상대 장부) |
| Risk | 본인 데스로 자팀 기대 골드(속도)가 내린 몫 | 포함 |

G = 현재 골드 + V (V = 앞으로 10분 기대 수입). 속도형 정의는 결정 27 (`spec/03` §3.2).

`LwRC_i = C_i + D_i + Risk_i` (골드 단위). D는 상대 장부의 하락이라 5명의 LwRC 합은 팀 골드 변화보다 크다 — 의도된 성질.
