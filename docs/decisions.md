## 2. 이번 버전 범위 밖

- 시야를 G 상태 피처로 넣는 것 (이번에는 배분에만)
- 교전 판정의 공간 조건 (현재 시간 인접성만)
- 팀 효과 분리
- 승리 환산 (LoL WAR — 별도 설계)
- 라이브(경기 중) 산출

## 3. 산출 후 공개 전에 고칠 것 (이 저장소 밖)

- 블로그 ⑥ §8 "LwRC+ ... means contribution to winning" → 퍼포먼스를 골드로 표시한 것, 승리 환산은 별도 지표
- 블로그 ⑥ Risk 설명("데스부터 부활까지의 손실") → 데스 단위 한계 비용으로 갱신
- 웹 홈 문구 "how much each player turned resources into wins" → 퍼포먼스 정의로 수정
- 웹의 표시용 LwRC+ 재계산 로직(`100 + pg × k` 등) 제거 → 이 저장소 출력값을 그대로 표시
- `references.md` §2 야구 문헌 링크 유효성 확인
