# rorr-lwrc

LwRC+ (LoL weighted Resources Created Plus) — RORR의 선수 퍼포먼스 지표, 2026 시즌 산출.

- 범위: 2026 LCK + First Stand + MSI + Worlds
- 출력: 8개 scope × 선수/팀 (`all`, `lck`, `lck_s1~s3`, `fs`, `msi`, `worlds`)
- 사양: `docs/` · 설정: `config/lwrc.yaml` · 출력 스키마: `schemas/`

Claude Code로 작업할 때는 `CLAUDE.md`부터 읽힌다.
