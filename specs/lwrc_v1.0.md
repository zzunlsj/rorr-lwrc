## 1. 정의

| 기호 | 정의 |
|---|---|
| G(state) | `E[팀 최종 골드 \| 현재 게임 상태]`. 이 지표에서 유일한 통계 객체 |
| ΔG | 두 시점 사이 G의 차분. 이벤트 가치는 사람이 정한 상수가 아니라 ΔG로 정한다 |
| LwRC | 선수에게 귀속된 ΔG의 누적 (C채널 + D채널 + Risk) |
| LwRC+ | `100 × (선수 LwRC/분) ÷ (기준 집단의 같은 포지션 평균 LwRC/분)` |

## 2. 입력 전제 (전처리 규칙 요약, 상세는 CLAUDE.md §5)

- `gameTime`은 ms 단위이고 CSV 행은 시간순이 아니다. 항상 `gameTime`으로 정렬한다.
- 에픽 몬스터는 `monsterType ∈ {dragon, baron, riftHerald, VoidGrub}`만 쓴다.
- 장로 = `dragon` + `dragonType='elder'`. 영혼을 판정할 때는 장로를 뺀다.
- `deathRecap`은 list다. `source='Champion'`만 남기고 casterId별로 physical+magic+true를 합산한다.
- 팀 골드는 `stats_update.teams[].totalGold`의 관측값을 쓴다.
- `stats_update`는 1Hz다.

## 3. 채널

| 채널 | 의미 | 보존 항등식 포함 여부 |
|---|---|---|
| C | 우리 팀 G 상승분의 귀속 | 포함 |
| D | 상대 팀 G 하락분의 귀속 | **제외** (상대 G의 변화는 다른 장부) |
| Risk | 본인 데스로 생긴 반대 방향 ΔG | 포함 |
| 팀 버킷 | 개인에게 귀속되지 않은 잔여 | 포함 |

## 4. 클러스터

- 씨앗 이벤트: `champion_kill`, `epic_monster_kill`(에픽 필터 적용 후), `building_destroyed`
- 창: 씨앗마다 ±10,000 ms
- 병합: 인접 창 사이 간격이 10,000 ms 이하이면 연쇄 병합
- 경계: 게임 시작과 종료 시각에서 자른다
- 틱 구간 `(t_{i-1}, t_i]`은 **중점** 기준으로 정확히 하나의 버킷(클러스터 k 또는 드리프트)에 귀속한다.
  창 경계 시각의 G값으로 따로 계산하지 않는다 (이중계상 방지).

## 5. 노이즈 임계

- δ_noise = **110 골드/초** (튜닝 범위 60~250)

## 6. 콜드스타트 배분

| 상황 | 배분 |
|---|---|
| 클러스터 ΔG_us > 0, 딜 있음 | deathRecap 딜 비중 |
| 클러스터 ΔG_us > 0, 딜 없음 | killer + assistants 균등 |
| 클러스터 ΔG_us > 0, 둘 다 없음 | 팀 버킷 |
| 클러스터 ΔG_us < 0 | 클러스터 안에서 죽은 우리 팀 선수에게 균등 (Risk) |
| 드리프트 | 개인 `totalGold` 증가분을 본인 C로 |
| 상대의 정상 획득으로 생긴 음수 ΔG | 팀 버킷 |

## 7. G 모델

- 인터페이스: `G(state) -> float`. 임시 G(R(m) 테이블)를 학습 G로 **함수 하나만 바꿔서** 교체할 수 있게 만든다.
- 순서: v1 = 분 버킷 선형회귀(계수 해석 가능) → v2 = LightGBM. 처음부터 GBM을 쓰지 않는다.
- 학습셋: 1Hz 프레임을 2~10초 간격으로 샘플링한다. 귀속 평가는 1Hz 전체로 한다.
- 누수 방지: **leave-one-tournament-out**. 대상 대회를 뺀 데이터로 학습한 G로 그 대회를 평가한다.
- 후반 생존 편향: 28분 이후는 표본이 줄어든다. R(m)과 잔여 기대에 isotonic(단조 비증가) 스무딩을 적용한다.
- 패치 처리: **미확정** (§10-3)

## 8. 정규화 (LwRC → LwRC+)

1. 선수 LwRC/분을 계산한다.
2. 윈저라이즈 ±3σ
3. prior 수축: `w = (n × 실측 + k × prior) / (n + k)`, k = 10
4. 기준 집단의 포지션 평균으로 나누고 100을 곱한다.
   - 기준 집단: 2026 전체 풀 × 포지션 (확정)
   - 음수 표기: 음수 허용, 바닥 처리 없음 (확정)

## 9. QC 게이트 (CLAUDE.md §6)

1. 기대 게임 대조 (`manifest/expected_games.csv`)
2. 1Hz 연속성: 틱 간격 p95, 최대 간격, 결측 구간
3. 보존 항등식, ε = 1.0 골드:
   `Σ개인 C + Σ Risk + 팀 버킷 = 실제 최종 팀 골드 − G(초기 상태)`
4. 틱 구간 완전 분할 (중점 기준)
5. 팀 버킷 크기를 G 품질 진단값으로 리포트한다

QC에 실패한 경기는 L3에서 빼고 목록으로 보고한다.
